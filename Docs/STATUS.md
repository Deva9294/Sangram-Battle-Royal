# SANGRAM development status

## Committed to main
- Unity 2022.3 project skeleton and package manifest
- Third-person character controller
- Follow camera rig
- Hitscan weapon and reload
- Health/damage component
- Practice enemy AI
- Shrinking safe-zone prototype
- Editor menu that generates a test arena with player, cover and bots
- Android build checklist

## Current limitation
This is an early offline prototype foundation. The generated scene is not yet committed as a Unity scene asset; open the project and use Tools > SANGRAM > Create Prototype Scene. It has not been compiled in Unity or tested on an Android device in this environment.

## Next milestones
1. Touch joystick, touch-look and action HUD.
2. Proper player/enemy animations, weapons, sound, VFX and Indian map art.
3. Loot, inventory, parachute, match flow and results screen.
4. Multiplayer architecture and dedicated authoritative server.
5. Android performance profiling, QA and signed APK.
